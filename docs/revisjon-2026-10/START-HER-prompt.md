2. Åpne Claude Code i repoet.
3. Lim inn teksten under.

---

```
Vi skal revidere nrth.no. Alt du trenger ligger i docs/revisjon-2026-10/.

1. Les README.md, 01-brief.md og CLAUDE.md i den mappen først. Kopier CLAUDE.md til roten av repoet i PR 1.
2. Les assets/site.css, index.html og services/index.html, så du kjenner komponentene som skal gjenbrukes.
3. Følg PR-planen i 08-oppgaver-og-akseptkriterier.md, ett steg om gangen. Start med PR 1 (struktur).
4. Én branch og én PR per steg. Kryss av akseptkriteriene i PR-beskrivelsen og legg ved skjermbilder av desktop (1440 px) og mobil (390 px).
5. Bruk teksten i 03-tekst-norsk.md og 04-tekst-engelsk.md ordrett. Plassholdere i [hakeparenteser] blir stående.
6. Stopp og spør meg hvis noe i pakken er uklart, motsier koden, eller hvis du vil endre hvordan siden bygges.

Når PR 1 er klar: vis meg en oppsummering og vent på godkjenning før du går videre til PR 2.
```
